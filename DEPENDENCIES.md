# Project Dependencies

This markdown file lists all the packages required for this project. You should install these before running or developing the application.

## Main Dependencies
These are required to run the app:

- lucide-react
- react
- react-dom

## Development Dependencies
These are required for development, building, and linting:

- @eslint/js
- @types/react
- @types/react-dom
- @vitejs/plugin-react
- autoprefixer
- eslint
- eslint-plugin-react-hooks
- eslint-plugin-react-refresh
- globals
- postcss
- tailwindcss
- vite

## Installation
To install all dependencies, run:

```bash
npm install
```

Or, to install a specific package:

```bash
npm install <package-name>
```

---
For more details, see the package.json file.
